# Image Grid With Category-Based Filtering

## Aim
To design and implement a responsive image grid with category-based filtering using modern layout techniques such as CSS Grid and Flexbox.

## Objective
To display food items in an organized gallery, allow users to filter images by category, and ensure the layout adapts smoothly to different screen sizes.

## Theory
An image grid is a visual layout technique used to present multiple images in a structured and attractive format. CSS Grid is suitable for arranging items in rows and columns, while Flexbox is useful for aligning controls such as filter buttons.

Category-based filtering improves user experience by reducing clutter and showing only the relevant content. In this implementation, each image card is assigned a category through a data attribute. When a filter button is selected, JavaScript compares the selected category with each card's data value and hides or displays cards accordingly.

Responsive design is achieved by using flexible grid columns with automatic wrapping, so the gallery adjusts to mobile, tablet, and desktop screens without losing readability or spacing.

## Conclusion
The image grid with category-based filtering makes the content easier to browse, visually organized, and responsive on all devices. This improves usability and demonstrates the practical use of HTML, CSS, and JavaScript in interactive web design.
